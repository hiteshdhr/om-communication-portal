# OCW Website Image Library

This folder contains the 41 uploaded website images organized for the OCW security, surveillance, telecom and infrastructure website.

## How to use
- Use the descriptive filenames inside the numbered folders for the website.
- `00-originals/` preserves the original uploaded filenames.
- `08-review-needed/` contains assets that should be reviewed before production use.
- Avoid stretching images. Use `object-fit: cover` for cards and `object-position` as needed.
- Keep the same visual treatment across pages: clean, professional, blue/navy security/technology look.
- Do not add extra text overlays to images that already contain embedded text.
- Prefer real/service-focused imagery over generic product-only images.

## Recommended image roles
- `02-homepage/hero/` = main homepage hero
- `02-homepage/services-preview/` = homepage services section
- `03-services/` = individual service pages/sections
- `04-industries/` = industry/application sections
- `05-about/` = About/Why Choose Us/team context
- `06-projects/` = future project/case-study gallery
- `07-gallery/` = optional general gallery
- `08-review-needed/` = don't deploy without review

## Important visual QA
Some generated/stock-style images include visible brand/certification markings or embedded text. Do not represent those markings as OCW branding, certifications, partnerships, or product affiliations. Replace or edit such assets if needed.
